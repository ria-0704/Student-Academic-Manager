# Handwritten Answer OCR Testing

## Handwritten Answer Recognition

### Work Done

This week, I worked on the handwritten answer feature in the mock practice module. I tested the process of uploading a handwritten answer image and converting it into text using Gemini Vision.

I tested the OCR with different handwritten answers and compared the extracted text with the original answer to identify recognition errors.

The image is uploaded through the frontend and sent to the backend as multipart form data. The backend converts the image buffer into Base64 and sends it to the Gemini Vision model for transcription.

```javascript
const base64Image = req.file.buffer.toString('base64');

const extractedText =
    await extractHandwritingFromImage(
        base64Image,
        req.file.mimetype
    );
```

## Problem Faced

The main problem was that the extracted text was not always exactly the same as the handwritten answer. Some words could be misread depending on the handwriting or image quality.

This was important because even a small OCR mistake could affect the answer that is later evaluated.

## Solution

Instead of directly using the OCR output as the final answer, I added a **review and edit step**. The extracted text is displayed in an editable text area so that the student can check and correct any mistakes before confirming the answer.

```jsx
<textarea
    value={extractedText}
    onChange={e => setExtractedText(e.target.value)}
/>
```

I also handled cases where no text could be extracted and provided an option to re-extract or upload a different image.

This made the OCR feature more reliable because the student can verify the recognized answer before it is sent for evaluation.
