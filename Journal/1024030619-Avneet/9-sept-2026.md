# Mock Practice and Answer Submission

## Mock Answer Submission

### Work Done

This week, I worked on testing the mock practice functionality of SAM. I tested both typed answers and answers obtained through handwritten OCR to make sure they could be submitted and evaluated correctly.

I also tested different question types, marks, and difficulty levels to check whether the mock question generation and answer evaluation were working correctly.

During testing, I verified that the student's answer is stored as an attempt before the evaluation process is performed.

## Problem Faced

While testing the mock module, one issue was handling invalid or incomplete answers. An empty answer or an answer containing very little text should not be submitted for evaluation.

There was also a need to make sure that the question being answered actually belonged to the logged-in student.

## Solution

I added validation before processing the answer. The system checks whether the question ID and answer are present and whether the answer contains meaningful text.

```javascript
if (
    !question_id ||
    !student_answer ||
    student_answer.trim().length < 5
) {
    return res.status(400).json({
        message: 'question_id and a meaningful student_answer are required.'
    });
}
```

I also verified the question using both the question ID and the logged-in user's ID before saving the attempt. This prevents an attempt from being created for a question that does not belong to the current user.

After successful validation, the answer is stored and passed to the evaluation function for scoring.
